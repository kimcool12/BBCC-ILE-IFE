Drop your images into the matching folder, then use the path in src/data/siteContent.js
  hero/       slideshow background photos      -> "/images/hero/slide1.jpg"
  people/     "The Top 1%" photos              -> "/images/people/person1.jpg"
  events/     event card photos                -> "/images/events/event1.jpg"
  leadership/ leader photos                    -> "/images/leadership/leader1.jpg"
  pastor/     pastor photo                     -> "/images/pastor/pastor.jpg"
Videos: put them in a new folder (e.g. public/videos) and reference "/videos/name.mp4".

NOTE: the current images are grey/colour placeholders. Replace them by saving your own photos
with the SAME file names (e.g. hero/slide1.jpg), or change the paths in siteContent.js.
